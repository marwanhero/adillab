# Project: Spelling Success Platform

**Goal:** Build a web application for children with spelling difficulties (dyslexia/learning delays).

**Target Audience:** Children (require simple UI, bright colors, large text, dyslexia-friendly fonts) and Parents/Teachers.

## Core Features
1. **Games:** Interactive spelling games (Drag & drop letters, word matching).
2. **Video Tutorials:** Section for embedded educational videos on phonics.
3. **Ideas & Mnemonics:** Visual cards to help memorize difficult words.
4. **Challenges:** A daily challenge system to track streaks and progress.

## Tech Stack
* HTML5, CSS3 (Modern, responsive, accessible).
* JavaScript (Vanilla JS for game logic).
* No complex backend yet (Local storage for progress).

## Design Rules
* Use high-contrast colors.
* Avoid "walls of text."
* Use standard, clear fonts (like Comic Sans, Open Dyslexic, or rounded sans-serifs).
